# Passive pixel sensor

The preserved [observe_public_pixels.py](../scripts/observe_public_pixels.py) and
[public_pixel_predicate.py](../scripts/public_pixel_predicate.py) helpers
operate on public pixels. They are optional sensor utilities, not a gameplay
controller or required phase. Inspect their supported CLI before using them for
a specifically assigned public pixel claim. Their tests are preserved historical
maintenance assets, not an automatic QA gate. Directed capture is owned by the
installed qa-execution skill; no card or independent replay is required.

Maintenance sources: [observation checks](../scripts/test_observe_public_pixels.py)
and [predicate checks](../scripts/test_public_pixel_predicate.py), retained without execution.
