# ADR-005 — Preserve genuine QA saves for repeated suffix checks

- Date: 2026-09-11
- Status: accepted QA-copy authorization; implementation and capture pending
- Scope: isolated QA setup and evidence reuse, not player-facing save behavior

## Decision source

The user requested study of Save/Load reuse to reduce time reaching late campaign scenes. After learning that the final choice overwrites the single autosave, the user explicitly authorized keeping a copy of the QA save.

## Direction

Preserve native saves produced by legal QA gameplay before the final choice and resume isolated copies through native Continue for repeated compatible checks. Retain the native payload, matching save index and provenance; never replace a player's personal save or edit campaign facts. Public single-autosave, irreversible decisions and revision validation remain unchanged.

The [feasibility study](../qa-save-reuse-analysis.md) records actual native boundaries, storage requirements, the executor gap and honest limits. No suitable archived native save pair was found in the inspected QA artifacts. Capture is therefore assigned to the first legal checkpoint on the new stable implementation; this ADR does not claim an existing copy.

## Task ownership

- Task 05 prepares and verifies capture/pre-boot restore support, using actual native saves and isolated fixtures. Any generic executor storage-lifecycle extension has its own focused verification; game behavior is not altered for test convenience.
- Task 08 plans banks per distinct roster/history, prefix provenance, compatibility checks and retained full-run coverage.
- Task 09 captures the real Council/pre-ending bank after implementation is stable and reuses it for compatible suffixes, preserving immutable masters and measuring actual elapsed time.

No additional task or approval pause is required. A loaded suffix is reported as a resumed run; its earlier navigation is proven only by the linked producer run. Relevant source/revision changes invalidate cache entries rather than bypassing native compatibility checks.
