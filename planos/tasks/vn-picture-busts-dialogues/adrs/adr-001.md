# ADR-001 — VNPictureBusts for all existing dialogue busts

- Date recorded: 2026-09-11
- Status: historical proposal superseded by ADR-002
- Current authority: interview decisions in ADR-002; subsequent execution authorization in [ADR-003](adr-003.md). The withdrawn approval below remains historical.

## Decision source

The user requested `VisuMZ_2_VNPictureBusts` for all dialogues that have busts, including isolated character lines and dialogues with one or more characters. They requested identification of those dialogues, their current construction and the required changes. This authorizes local investigation and specification.

## Requested scope

Use the named plugin for dialogue busts; include both single and alternating-speaker dialogue in the inventory. Preserve GDD authority, current content statuses and unrelated native picture uses. The request does not approve new dialogue, multiple simultaneously visible busts, additional character art or implementation.

## Findings and proposed authoring decision

Static inspection found the plugin already active and called from EventBridge for 63 sections / 103 Show Text commands. No native event contains its commands. The proposed increment moves these existing calls into the authored event sections and constrains the content parser accordingly, preserving the current one-bust-at-a-time composition.

On 2026-09-11 the user requested removal of the approval record and required an interview review before actual approval. The subsequent interview selected native event authorship with ensemble staging rather than preserving the single-bust presentation proposed above. [ADR-002](adr-002.md) records those accepted decisions and the consolidated spec owns the current proposal. This record preserves the original investigation; it is not authority for the replaced single-bust design. Implementation and task creation have not occurred and must not proceed on the basis of the removed approval.
