# ADR-001 — Minimal Bridge, native authorship and provider controls

Status: accepted. On 2026-09-12, the user approved the consolidated [spec](../spec.md) and its technical proposals with “Aprovo”.

Subsequent amendment: [ADR-002](adr-002.md) records the user's direct native content calls and default image-loading fallback after review round 01. It supersedes only the corresponding configuration/loading details; the other decisions below remain in force.

Later scope addition: [ADR-003](adr-003.md) includes CoreEngine preload for all tavern images; the general preload exclusion remains applicable to the rest of the game.

## Context

The current Bridge initializes the campaign but also indexes constrained narrative sections, renders UI, audits content/saves, reconstructs busts and supplies QA controls. Turning it off removes the campaign object that CE67 accesses before the tavern stage. The user wants a playable game with direct editor authorship and the enforcement layer removed, not an unconfigured disabled plugin.

## Decision

Keep Bridge as campaign-to-event integration and checkpoint coordination. CampaignRules owns mechanics; native events own narrative/presentation and editable configuration. Installed providers own their features; the approved local presentation adapter is limited to explicitly retained UI/audio integrations. Do not transfer the rejected QA/editorial enforcement to that adapter.

Remove mandatory editorial fields, formatting restrictions, command allowlists, asset manifests, manual revision generation, expeditionQA, the custom invalid-campaign barrier and save revision/envelope audits. Preserve actual domain legality and native error handling. Remove automatic bust erase/reconstruction and runtime memorial crops; events explicitly author exits/composition and use prepared images.

SaveCore replaces the single-campaign file policy with a dedicated file selected for each new campaign, autosave in that file and a Continue file picker. Remove Bridge's slot-zero overrides. No arbitrary manual rewind saves, cloud storage, save erasure or guaranteed legacy structural migration are added.

AUTO and FAST of Extended Message replace the project's instant text-skip mechanism for already-read passages. Bridge supplies reading facts and receives ordinary completion. HIDE, keyboard/focus, reduced motion, confirmation handling and live ME-volume support stay outside Bridge. Credits use native rolling text at speed 2, allow native acceleration and retain a skip control returning to title. Free avatar movement and the RPG menu remain unavailable through presentation/native event controls.

## Superseded contracts

This decision supersedes only the conflicting parts of the initial MZ ADRs 003/005/012/015/037 and subsequent native bust-restoration contracts: single-file selection, prohibited AUTO/FAST, instant seen-text skip, mandatory content-revision compatibility and Bridge-owned visual restoration/enforcement. Semantic checkpoint timing, campaign mechanics, HIDE behavior, keyboard access, one-gesture confirmation and current creative statuses remain intact. Completed specs and reports remain historical, not rewritten evidence.

The canonical GDD amendment records the accepted behavior. The [interview ledger](../../../../docs/design/2026-09-12-eventbridge-runtime-e-entrevista.md) supplies the individual acceptances, including corrections to initial recommendations.

## Consequences and limits

Migration must update native event callers, tests, tools and documentation together. Native provider integration, preserved save/interpreter state and rolling-credit skip need fresh implementation evidence. The approved directions are not proof that deleting every hook alone works. No runtime change has been made by this spec-authoring work. Preloading images remains a separate known issue explicitly excluded from this increment.
