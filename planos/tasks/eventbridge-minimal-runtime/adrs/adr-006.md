## Context

At planning time, Gorvak's Map037 owned the actual interaction, including the menu, text, bust commands, selection responses and explicit return. The remaining seven heroes used CE006–012 plus four reading units each, CE086–113. Their control structures matched after normalizing hero identity and unit references, but their text and artwork remain individual. Tasks19/20 subsequently move H2–H8 into Maps038–044 and retire their35 displaced bodies. The prologue is local to Map002 after task21; the graph and verification own the current campaign-slice results.

The pre-migration inspection found other scenes with maps whose authorship remained behind shared selectors: prologue Map002 → CE001 → CE114–116; epilogues Maps029–036 → CE040 → CE041 → CE306/308/310/312/314/316/318/320; endings Maps025–027 → CE040 → CE336 → CE055–057; Council Map023 → CE040 → CE335/054/041/053; encounters Maps007–022 → CE040 → CE262 → CE013–028.

These autoruns are functional gameplay entries. Their migration transfers ownership; deleting them as if they were the old editorial shortcuts would break the game. Campaign scenes also differ from observational hero visits: completing a passage can advance campaign state and schedule a checkpoint.

## Decision

1. Extend the accepted Gorvak interaction model to H2–H8, in two bounded batches. Preserve each hero's content, identity, formation rules and reading history; calibrate presentation per artwork. Create seven child maps under Taverna, allocating IDs from the execution checkout rather than reserving them during planning.
2. Put the prologue, eight epilogues, three endings, Council and sixteen encounter-specific bodies in their existing maps. Include the actual native text, choices and scene-specific presentation, not a new wrapper pointing to the displaced controller. Shared functional helpers remain allowed.
3. Introduce campaign-map handoff through a tested H1 epilogue slice before migrating the remaining campaign scenes. A migrated map owns its local execution; CE040 retains necessary cross-scene routing and not-yet-migrated paths. It must not also execute the same migrated content. CampaignRules remains the sole authority for phase, passage, eligibility, outcome and progression.
4. Each slice removes its displaced Common Event bodies after migrating every functional consumer. Set the exact slots to `null`, preserve surviving IDs and keep observational reading identities even when their old Common Event slots are empty. Do not leave dead wrappers, empty named substitutes or duplicate editable prose. A final task reconciles transitive orphans across all slices.
5. Reuse tasks15/16 as the ordered QA tail. Reopen their affected scope and the aggregate implementation/verification flags; retain prior execution evidence and the accepted Gorvak organization as dated history.

Tavern orchestration and a dedicated credits map remain a lower-priority follow-up. Destinations, roster, sacrifice, configuration, preload, audio, checkpoints and memorial animation are retained functional units unless the migration proves a particular helper has lost every consumer. No new story, assets, gameplay decision, checkpoint policy, vendor edit or runtime dispatch registry is introduced.

## Handoff invariants

The map ID is a presentation location, never an independent campaign phase. Entry queries the current campaign phase and expected identity. Only the map matching those facts executes its local content. A completed local passage refreshes queries; the next local passage runs only if it still belongs to that map. Otherwise execution reaches the existing native routing boundary and finishes the source interpreter path before the destination autorun assumes ownership.

Task22 records the concrete native call/return and transfer contract, including nested interpreters, same-map continuation and Continue from an already saved boundary. Council and encounters depend on that tested contract. Copying CE040 into every map or adding a generic Bridge content dispatcher is not an acceptable implementation.

Observational hero reading uses Presentation's explicit numeric unit IDs. Campaign reading retains the existing semantic passage identities and explicit CaptureContext/ReadingComplete boundary, including the ordinary checkpoint owner. These are distinct state stores and must not be combined. Pictures, input permissions and audio keep explicit lifetimes across transfers; transfer itself adds no autosave.

## Retirement safeguards

An executable reference audit must cover native call117, map/troop pages, choice tags, provider/configuration selectors, autorun/parallel triggers and project code that reserves or calls Common Events. Tests and maintained authoring/QA recipes must also move to the live path. Zero direct call117 references alone is insufficient.

Examples that must survive while referenced: CE004 configuration, CE030–037 choice-focus callbacks, CE064/065 HIDE callbacks, CE350's parallel trigger, CE351 preload and encounter death-inscription units reused by CE347 in the memorial. Numeric observation-unit arguments that preserve read history are logical identities, not calls to the retired Common Event bodies.

Each removal has a before/after source and consumer record in the implementation evidence. The audit is a development check, not a shipped manifest or a new editor prerequisite. Native saves retain serialized interpreter command lists, so a same-structure text edit need not replace text already stored in an existing save; a New Game uses the edited map. Old interpreter saves receive no migration guarantee; keep personal saves untouched and prove Continue on native checkpoints earned by the changed implementation.

## Alternatives and consequences

Keeping all existing Common Events would preserve working execution but leave the accepted authorship improvement incomplete. Removing only the callers while retaining unused bodies would create competing editorial sources. Expanding to every panel/helper would add unnecessary map transitions and duplicate shared behavior. The selected scope follows coherent interactions and scenes.

The main cost is transferring ownership out of CE040 without duplicating passage completion, consequences or writes. Migration is therefore ordered: heroes → prologue → epilogue handoff pilot → other epilogues and endings → Council → A1 pilot → remaining encounters → orphan audit → existing QA tail. Technical passage and checkpoint coverage precedes the broader families; human usability, framing and audio judgments remain separate.
