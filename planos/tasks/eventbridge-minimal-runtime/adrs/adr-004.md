# ADR-004 — Keep FAST as the only reading acceleration button

Status: accepted by the user on 2026-09-14, during implementation review.

The user requested: “pode remover o BOtão de Auto. deixa somente o botão de fast.”

Remove AUTO from the installed Extended Message console's button list. Keep FAST, Configurações and HIDE. FAST remains player-selected and available only for units already read in the current campaign; unread text and choices retain their permission/reset rules. AUTO has no keyboard shortcut. No vendor source, campaign state, event list or save structure changes.

This replaces the requirement to offer AUTO in RQ-010, V-009/S07 and the current reading-control contracts. Existing AUTO test results remain historical evidence, not a requirement to retain that button. Update the existing native-controls cases and directed surface scenario to assert AUTO's absence and exercise FAST. The four human acceptance decisions remain pending; the UI decision now assesses FAST without AUTO. This amendment belongs to the still-open increment and does not reopen unrelated creative decisions.
