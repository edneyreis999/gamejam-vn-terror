# ADR001 — Slot focus and one authored visual source

Status: accepted by user direction, 2026-09-11.

The user authorized the combination of standardized portrait assumptions, positional focus and reconstruction from the same authored presentation. The subsequent correction explicitly says to keep every PNG and generate none; the user will standardize/import portraits later in the editor. Therefore uniform dialogue scales and positions are implemented now, with final art framing deferred. This supersedes the prior increment's per-art transform duplication and per-box restore helpers, not its narrative, eligibility, controls or save rules.

Use a finite Focus command in the existing EventBridge, invoked by native positional helpers. Entry commands remain native VNPictureBusts commands. Shared focus operates from entry-authored base targets, never cumulative current interpolation. Reconstruction derives final effects from native commands and explicit visual source references between sections; no text/domain replay and no independently editable JS layout table. No new dependency/vendor edit.

Execution is authorized now; no additional spec/sample approval gate. No commits/publication. The existing inaccessible MZ window is not a new required repetition; CLI, source and real Chrome cover this implementation. Final framing of replacement portraits belongs to the user's later asset edit and is not claimed here.

RQ003 authoring clarification: an allocated position may be empty because of native roster conditions or because its entry has not run yet. Focus on that empty position leaves the current composition unchanged in both playback and reconstruction. This does not authorize foreign slots or incomplete entry transforms, which remain validation errors.
