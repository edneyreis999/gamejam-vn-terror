Os [prompts completos](prompts.md) registram as instruções de cada geração. As três imagens foram inspecionadas visualmente: apresentam os marcos dos destinos, sem texto de interface ou personagens. Os PNGs foram copiados sem edição; os originais foram preservados.

Estes arquivos são assets de desenvolvimento, conforme o ADR-002 da spec incremental `prototype-v2-gdd-layouts`. A geração não substitui a direção de arte final do GDD nem constitui aprovação artística da entrega. Sua integração ao protótipo faz parte da atualização ainda em especificação.
