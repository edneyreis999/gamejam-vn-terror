# Assets and provenance

- Outfit / Outfit Medium: bundled `fonts/outfit-OFL.txt`.
- Averia Libre: bundled `fonts/averialibre-OFL.txt`.
- Cinzel Decorative: bundled `fonts/cinzeldecorative-OFL.txt`.
- Coreto brand icons and console assets: retained from the independent 1.2.0 package and installed 1.3.0 theme. This release does not grant rights to third-party engine/provider files, which are not distributed here.
- `assets/CoretoWindow.png`: approved parchment texture promoted from the consumer's `img/system/Window.png` on 2026-10-29, at the owner's explicit request. Generated/edited visual reference from the preceding design iteration; final delivered pixels and hash are recorded in the release manifest.
- `profiles/dryland/Window.png`, `Dryland_FinalReunite.png` and `Dryland_FinalDestroy.png`: existing approved Dryland consumer assets, distributed only with its opt-in profile under the owner's installation request. These are the exact illustrations selected by the reference registry; no replacement art or placeholders were introduced.
- Feather, brush and filled dripping seal: code-native paths in `src/runtime/ink.js`, implementing the approved brand direction. The seal is a new simplified drawing, not a copied skull/emblem image from the external reference sheet.

The earlier independent package did not supply a separate code license grant. Distribution here preserves that ownership position and the existing font licenses; it does not invent an open-source license. Consuming studios must retain rights to their RPG Maker and Coreto providers.
