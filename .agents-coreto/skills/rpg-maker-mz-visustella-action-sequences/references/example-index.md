# Sanitized Action Sequence examples

These XML fixtures are illustrative, non-normative, self-contained projections of complete RPG Maker MZ Common Event command lists. Command order and payload shape are preserved; consumer IDs, assets, and project code are placeholders. Structural XML validation passed. Runtime Playtest is not claimed.

Load only the example whose pattern matches the task.
