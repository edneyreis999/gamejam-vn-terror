## Context

The user explicitly requested one physical-trap map, one supernatural-trap map, and child maps for each trap, replacing shared encounter-stage presentation.

## Decision

Create two parent maps in the native editor hierarchy: Physical Traps and Supernatural Traps. Each owns eight exclusive native child maps, corresponding to A1–A8 and B1–B8. Each child is an independent map. Use explicit native transfers and a validated stable encounter-to-map mapping; preserve shared common-event prose and campaign-rule ownership.

Parent-child relationships organize editing and do not automatically transfer the player. No new playable hub or trap-selection surface is implied. The currently assigned encounter determines the destination map, independently of route identity. Preserve encounter pools, stable draws, progress and semantic autosave boundaries.

## Consequences

Each trap can be authored in its own map context. Validate complete unique mappings and parent links, and verify transfers do not redraw encounters, duplicate consequences or add incidental autosaves. Other narrative map organization remains unchanged.
