## Decision

The user removed the above-head hover profile and requested that all its information appear in the hero dialogue. Hover and keyboard focus now only highlight the hero. Conversar presents name, pronouns, race, profession, public summary and status through native bottom dialogue with VNPictureBusts, together with the existing presentation line. Split into readable authored passages as necessary; wording remains provisional pending editorial review.

This supersedes earlier above-head profile requirements for this increment, including ADRs 019–020. Do not expose hidden competencies. Keep the explicit action menu, selection acceptance, full-party feedback and removal behavior unchanged.

## Consequences

No profile overlay is needed. Native events and MessageCore own the dialogue; VNPictureBusts owns speaker presentation. Verify all public information remains available through Conversar and focus produces no dialogue or formation mutation (IT-006).
