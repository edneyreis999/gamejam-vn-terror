## Context

The user accepted an exclusive Council map, a Finals parent with three outcome children, and a Memorial and Epilogues closing map, adding an explicit request for a child map per epilogue.

## Decision

Use that native editor hierarchy and eight exclusive hero-epilogue child maps under the closing map. Preserve shared common-event prose; use native transfers and stable validated map mappings. The rule owner supplies the selected outcome and eligible participants.

Preserve canonical eligibility: the conditional memorial depicts dead heroes; individual epilogues belong only to living climax participants, excluding reserves. A spoken description incorrectly associated the memorial with survivors; this is corrected here and is not a change to campaign rules.

## Consequences

Each ending and epilogue has its own editing context. Skip ineligible scenes, retain canonical order and do not add an ending-selection menu. Terminal Continue must retain the saved outcome without reopening the Council choice. Verify transfers, map-entry idempotence and absence of incidental autosaves in the composed runtime.
