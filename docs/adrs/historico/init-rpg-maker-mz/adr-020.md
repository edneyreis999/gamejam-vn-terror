## Context

After reviewing the Gorvak interaction example, the user replaced the speech balloon with native RPG Maker bottom text and a hero bust above it using the installed bust plugin.

## Decision

Conversar uses native Show Text at the bottom, integrated with MessageCore, and VNPictureBusts displays the speaking hero above the message window. Retain the existing fixed speech content. No lateral speech balloon is used in this increment's tavern conversations. This supersedes the speech presentation in ADR-019.

Keep hover/focus highlighting and the above-head public profile, and the separate Conversar/Selecionar menu. Talking does not change formation. End the conversation and restore the eligible tavern interaction context without leaving an obsolete speaker bust or advancing a selection from the closing input.

## Consequences

Reuse the installed bust plugin and native message presentation. Verify speaker identity, bottom-window placement, bust cleanup, input isolation and HIDE with the composed runtime. No new plugin purchase or dialogue content is introduced.
