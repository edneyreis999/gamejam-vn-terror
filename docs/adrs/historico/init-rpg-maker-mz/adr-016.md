## Context

During player-story review, the user requested an exclusive prologue map and another exclusive tavern map. The previous design used one campaign stage for both. The user also retained the prologue background image.

## Decision

Give the prologue and interactive tavern separate exclusive native editor maps. Keep the tavern background in the prologue. Use native transfers and map-specific orchestration with shared common-event prose. Later tavern returns do not replay the prologue. Retain native save transport and the accepted semantic checkpoint policy.

## Consequences

Authors can find and edit the two locations independently. Transfers and restored map/interpreter state need integration verification; entry events must not duplicate campaign mutations. No walking gameplay or new plugin is needed. Other scenes are not required to have exclusive maps by this decision.
