## B2. A Procissão das Almas

**Uma procissão de figuras cobertas atravessa o corredor sem mover os pés. Cada uma carrega uma vela acesa e um pano bordado com o nome de um dos heróis.**

**Quando uma chama se apaga, o herói ligado àquela vela começa a desaparecer das lembranças dos companheiros. Se todas se apagarem, ninguém no grupo conseguirá lembrar quem esteve ali.**

Como o grupo deve escapar?

1. Encontrar a única figura cuja sombra se volta para a própria vela.

2. Romper o feitiço que liga os nomes bordados nos panos aos heróis.

3. Desmanchar a costura de cada nome sem rasgar os panos da procissão.

**Falha:** todas as velas se apagam, e a procissão passa a reconhecer o grupo como parte do cortejo. Para afastar as almas, um dos heróis precisa tomar a vela da frente e seguir com os mortos. A procissão vai embora levando o herói, enquanto os outros conseguem escapar.

## Sucessos disponíveis

### 1. Encontrar a figura com a sombra errada

As sombras se alongam para longe das velas, menos uma, que se volta para a própria chama. Essa sombra revela qual figura guia o cortejo. O grupo passa pelo lado oposto. As outras almas seguem a guia, deixando livre uma passagem pelo corredor. Ao se afastarem das velas, os heróis recuperam as lembranças uns dos outros.

### 2. Apagar a ligação entre os nomes e a procissão

O encantamento que liga os nomes bordados aos heróis é rompido. As letras perdem a forma, até restarem apenas fios soltos no tecido. Sem essa ligação, as almas deixam de reconhecer o grupo como parte da procissão. Elas seguem pelo corredor carregando panos vazios até desaparecerem na escuridão.

### 3. Desfazer os nomes bordados nos panos

Os pontos de cada nome são soltos com cuidado, sem rasgar os panos. As letras se desfazem antes que as velas se apaguem. Sem nomes para levar, as almas abrem espaço no meio da procissão e deixam o grupo passar.
